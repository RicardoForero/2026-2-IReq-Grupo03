# Modelado de Requerimientos: Árbol de Metas KAOS

Este directorio alberga la documentación y estructuración del modelo KAOS (*Keep All Objectives Satisfied*) para la ingeniería de requerimientos del proyecto.

## Propósito
Descomponer las metas de alto nivel de la organización en submetas refinadas, hasta llegar a las operaciones concretas y asignar responsabilidades claras a los agentes del sistema (software o humanos).

## Estructura del Modelo
- **Metas (*Goals*):** Los objetivos globales que el sistema debe satisfacer.
- **Requisitos (*Requirements*):** Metas refinadas asignadas específicamente a agentes del software.
- **Expectativas (*Expectations*):** Metas refinadas asignadas a agentes externos (humanos, hardware heredado).
- **Obstáculos (*Obstacles*):** Posibles situaciones que impidan el cumplimiento de una meta y sus respectivas contramedidas.

## Contenidos del Directorio
- **`definicion_metas.md`**: Listado jerárquico de metas identificadas a partir de las entrevistas y el kickoff.
- **`refinamiento.md`**: Diagramas o tablas de descomposición (AND/OR).
- **`conflictos.md`**: Análisis de posibles oposiciones entre metas y sus resoluciones.
