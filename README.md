# Priorizacion: Diagramas 
Este directorio alberga los diagramas referentes al Sistema de Control de Inventario y Optimización de Rutas de Distribución **(SICIRD)**

## Propósito
Descomponer las metas de alto nivel de la organización en casos de uso especificos, reconstruir el recorrio del producto y visualizar como interactuan los actores con el sistema y los agentes externos.


## Contenidos del Directorio
- **`DCU-SICIRD.puml`**: Diagrama de contexto de casos de uso.
- **`DCU-#.puml`**: Diagrama de Caso de uso con vista de actor especifico.
- **`DCL-SICIRD.puml`**: CModelo de Dominio del Sistema SICIRD.
- **`DAC-#.puml`**: Diagrama de actividades de caso de uso especifico.
- **`DSE-#.puml`**: Diagrama de secuencia de caso de uso especifico.
- **`DES-01.puml`**: Historias de usuario documentadas en el formato requerido.
- **`README.md`**: Descripcion del directorio
