# Sistema de Control de Inventario y Optimización de Rutas de Distribución (SICIRD) — La Tradición

## Descripción del Proyecto
El proyecto **SICIRD** tiene como propósito especificar e integrar el control de inventario por lotes con la planificación y optimización de rutas de reparto para la empresa **La Tradición** (planta Barrio Libertador, Tunja, Boyacá). El sistema diferencia explícitamente los productos cárnicos perecederos (carne, morcilla, longaniza) que requieren cadena de frío, de aquellos no perecederos (manteca de cerdo), garantizando la trazabilidad sanitaria ante el INVIMA y habilitando el registro de entregas en modo offline para zonas con baja cobertura móvil.

## Registro de Stakeholders Clave

| :--- | :--- | :--- |
| **Gerencia General** | Alto / Alto | Patrocinador principal; aprueba presupuesto, alcance y prioriza el módulo de rutas. |
| **Jefe de Logística y Distribución** | Alto / Alto | Responsable de la planificación de rutas y coordinación de conductores. |
